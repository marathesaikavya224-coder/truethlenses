      03 / PROVENANCE & INTEGRITY

      Register a trusted reference

      ⌁

      Register a file you already trust. TruthLens compares future uploads against its SHA-256 fingerprint.

      #
      What a match means

      A match means the file has the same SHA-256 hash as a registered file. A mismatch means it differs from that reference. Neither result proves whether the content is factually true.
